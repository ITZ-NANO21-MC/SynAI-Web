# SYNAI - Agencia Digital

Este proyecto es una aplicación web moderna construida con Next.js 15, TypeScript, Tailwind CSS y Framer Motion para SYNAI.

## Estado del Proyecto: v1.1.1 (Estable)

### Características Implementadas
- **Diseño de Vanguardia**: Interfaz profesional con colores profundos y acentos neón (#0F0F1B, #8E44AD, #00F2FF).
- **Sistema de Temas Dinámico**: Soporte completo para Modo Oscuro y Claro con persistencia.
- **Geolocalización Avanzada**: Mapa interactivo con controles de navegación en la sede de Falcón.
- **Portafolio Interactivo**: Sistema de modales optimizados para mostrar detalles técnicos y arquitectura de software.
- **Comunicaciones Integradas**: Formularios con EmailJS y acceso directo a WhatsApp con alta visibilidad.
