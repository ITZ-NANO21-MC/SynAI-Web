# **App Name**: Synapse Studio

## Core Features:

- Dynamic Homepage Display: Engaging hero section, service highlights, animated statistics, and clear calls-to-action to capture visitor interest and guide them through the site.
- Detailed Services Page: A comprehensive section outlining all services offered, potentially including pricing structures, presented in an easy-to-digest grid format.
- Filterable Project Portfolio: A grid-based portfolio displaying past projects with image placeholders and text, featuring functionality to filter entries by categories.
- Interactive Image Gallery: A dedicated page or section featuring high-quality project images or studio photos, viewable with an integrated lightbox for a focused experience.
- Direct Contact Form: A fully functional contact form utilizing EmailJS for quick and efficient communication with potential clients, allowing for structured inquiries.
- Geoapify Map & Social Links: Integration of a Geoapify map for location display and always-visible floating buttons for WhatsApp and other social media connections.
- AI SEO Content Assistant: An AI tool to assist in generating optimized meta titles and descriptions for pages and portfolio items to enhance search engine visibility based on provided content and keywords.

## Style Guidelines:

- Primary color: #178282 (a deep, sophisticated cyan-green). This color conveys professionalism, trust, and modernity, grounding the digital presence in a sense of reliability.
- Background color: #F0F5F5 (a very light, almost white, cool grey). This subtle tone maintains clarity and offers a serene canvas for the primary content and branding elements to stand out.
- Accent color: #0DF280 (a bright, energetic green). Used sparingly for calls-to-action, highlights, and interactive elements, this vibrant hue creates visual interest and guides user attention effectively.
- Headline font: 'Space Grotesk' (sans-serif) for its modern, slightly tech-inspired, and assertive character, suitable for section titles and prominent text. Body text font: 'Inter' (sans-serif) for its excellent readability and neutral, professional appearance, ensuring clear communication of detailed information.
- Leverage a consistent set of line-based or subtly filled modern icons from 'react-icons' and 'shadcn/ui' to ensure clarity, intuitive navigation, and aesthetic unity across the application.
- Employ a responsive, component-based layout that prioritizes clean lines and ample negative space. A distinct global header for navigation and a detailed footer for supplementary links and social media will frame the content elegantly on all screen sizes.
- Implement subtle and purposeful animations using 'Framer Motion' for transitions, interactive elements, and particularly for the hero section's animated statistics, enhancing user engagement without distracting from core content.
